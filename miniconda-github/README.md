# Miniconda サーバー仮想環境構築ガイド

サーバー上でMinicondaを使ったPython仮想環境を作るための静的サイトです。

## 公開URL

https://shinnosuke-yoshida.github.io/miniconda-github/

## 内容

- SSHでサーバーへ接続する流れ
- 指定ディレクトリへのMinicondaインストール
- defaultsを外してconda-forgeを使う設定
- base環境の自動起動を止める設定
- bash起動時に特定の仮想環境を立ち上げる設定
- Conda仮想環境の作成
- 大気海洋解析向けライブラリの追加
- よくあるトラブル対応
