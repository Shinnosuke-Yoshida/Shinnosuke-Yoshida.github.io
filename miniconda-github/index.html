Server / Miniconda

サーバー上にPython仮想環境を作る。

Minicondaを指定ディレクトリに入れて、conda-forge中心の大気海洋解析環境を作ります。

手順を見る
ssh server
$ mkdir -p ~/apps/miniconda3
$ bash Miniconda3-latest-Linux-x86_64.sh -b -p ~/apps/miniconda3
$ source ~/apps/miniconda3/etc/profile.d/conda.sh
$ conda create -n ocean python=3.11
$ conda activate ocean

Overview

作業の流れ

01

インストール先を決める

ホームディレクトリ内に専用フォルダを作り、そこへMinicondaを入れます。

02

conda-forgeを使う

defaultsを外し、研究用ライブラリがそろいやすいconda-forgeに統一します。

03

仮想環境を整える

baseの自動起動を止め、必要ならログイン時に特定環境を起動します。

Install

Minicondaを指定ディレクトリに入れる

共有サーバーでは、あとから場所を把握しやすいように、先にインストール先ディレクトリを作っておくと扱いやすいです。

1. サーバーにログイン

手元のPCからSSHで接続します。

ssh ユーザー名@サーバー名

2. インストール先を作る

例では ~/apps/miniconda3 に入れます。場所は研究室やサーバーの運用に合わせて変えてください。

mkdir -p ~/apps/miniconda3

3. インストーラーを取得

Linux用Minicondaをダウンロードします。

wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh

4. 指定ディレクトリへインストール

-b は対話なし、-p はインストール先指定です。

bash Miniconda3-latest-Linux-x86_64.sh -b -p ~/apps/miniconda3
source ~/apps/miniconda3/etc/profile.d/conda.sh
conda --version

Settings

最初にやっておく設定

チャンネルをconda-forgeにそろえ、base環境が毎回勝手に立ち上がらないようにします。

defaultsを外してconda-forgeへ

大気海洋系のライブラリはconda-forgeにそろっていることが多いです。

conda config --remove channels defaults
conda config --add channels conda-forge
conda config --set channel_priority strict
conda config --show channels

base環境の自動起動を止める

ログインするたびに (base) が付くのを止めます。

conda config --set auto_activate_base false

仮想環境を作成

例では大気海洋解析用に ocean という環境を作ります。

conda create -n ocean python=3.11
conda activate ocean
python --version

bash起動時に特定環境を立ち上げる

ログイン時に毎回同じ環境を使う場合だけ設定します。

conda init bash
echo 'conda activate ocean' >> ~/.bashrc

Packages

大気海洋解析で入れておきたいライブラリ

NetCDF、格子データ、可視化、Jupyter、物理量計算でよく使うものをまとめて入れる例です。

基本セット

数値計算、表データ、NetCDF、Jupyterを扱うための土台です。

conda install numpy scipy pandas xarray dask netcdf4 h5netcdf h5py zarr cftime bottleneck numba jupyterlab ipykernel

可視化・地図

時系列、断面図、地図投影つきの図を作る時に使います。

conda install matplotlib seaborn cartopy nc-time-axis

大気海洋向け

海水物性、格子演算、スペクトル解析、気象データ処理などに便利です。

conda install gsw xgcm xhistogram xrft eofs cf_xarray metpy pooch

まとめて入れる場合

環境を有効化してから実行します。

conda activate ocean
conda install numpy scipy pandas xarray dask netcdf4 h5netcdf h5py zarr cftime bottleneck numba jupyterlab ipykernel matplotlib seaborn cartopy nc-time-axis gsw xgcm xhistogram xrft eofs cf_xarray metpy pooch

Troubleshooting

よくあるつまずき

conda が見つからない

source ~/apps/miniconda3/etc/profile.d/conda.sh を実行します。恒久的に使う場合は conda init bash のあと、再ログインします。

defaults がないと言われる

すでに削除済みなら問題ありません。conda config --show channels で conda-forge が入っているか確認します。

容量が足りない

使っていない環境を conda env remove -n 環境名 で削除し、conda clean -a でキャッシュを整理します。

bash起動時の自動activateをやめたい

~/.bashrc の conda activate ocean の行を削除します。

pipとcondaの依存関係が衝突する

先にCondaで主要パッケージを入れ、最後にpipを使います。依存関係が崩れたら新しい環境を作り直すほうが早い場合があります。
